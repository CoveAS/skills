# Planning

Write the steps that implement an agreement. Stop at the steps. The work itself is a separate
conversation, held after they accept the plan.

## The plan

A numbered list. Each step is a keyword phrase and one short sentence that says what it does.

## Where there is a choice

List every valid way to implement the agreement, with what each one costs and what it gives.

Stop before the branch when a choice changes the steps that follow. Ask the user to pick the path first.
Say what each option means for the rest of the plan.

## How to ask

- **One topic per turn.** Take as many turns as it needs.
- Be short. Several small turns beat one turn that covers everything.
- Make sure they understand the consequence of each option before they choose.

## When a choice changes the agreement

Go back to the agreement and update it. Then write the plan again from the step where the change
started, using the updated agreement.
